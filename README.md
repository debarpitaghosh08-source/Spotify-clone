# 🎵 Spotify Clone

A responsive **Spotify-inspired music player** built using **HTML, CSS, and Vanilla JavaScript**. This project recreates the basic UI and functionality of Spotify, allowing users to play, pause, skip tracks, and interact with a modern music player interface.

## 🚀 Live Demo

🌐 https://spotify-clone-one-neon.vercel.app/

---

## 📌 Features

- 🎵 Play and pause songs
- ⏭️ Next and previous track controls
- 📊 Interactive progress bar
- 🎧 Displays currently playing song
- 💿 Playlist with multiple songs
- ▶️ Individual play buttons for each song
- 🔄 Automatically plays the next song when one ends
- 📱 Responsive design
- 🎨 Spotify-inspired dark UI

---

## 🛠️ Tech Stack

- **HTML5**
- **CSS3**
- **JavaScript (ES6)**

## 🎮 How to Run

1. Clone the repository

```bash
git clone https://github.com/debarpitaghosh08/spotify-clone.git
```

2. Navigate to the project folder

```bash
cd spotify-clone
```

3. Open `index.html` in your browser.

No additional installation or dependencies are required.
